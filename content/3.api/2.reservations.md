## Reservations

To access a list of reservations create a `GET` request to `/reservations`

Available filters: 
1. `date` - filter reservations by date (Y-m-d), default is today
2. `court` - filter reservation by court ID 

Available sorts:
1. `from` - sorts by start of reservation
