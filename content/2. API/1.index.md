We have exposed some API endpoint for usage with third party services.

## Basic usage

In the V1 API we use basic REST JSON API. The endpoint for accessing the API is `https://api.sporty.plus/api/external/v1`

All requests need to have a header request: `X-Club: {club_id}`, the `club_id` is provided by SportyPlus team.

### Filters
There are a number of filters enabled on each endpoint. To use those filters send them as query params in filter array.

`?filter[date]=2026-03-01&filter[court]=1`

### Includes
We can also include relationships with some models. To include those, also request them in query params.

`?include=courts,players`

### Pagination

All requests will be paginated. 

To access other pages send the `page` query param, e.g. `?page=2`

### Notes

All date time variables are in UTC unless otherwise specified.
