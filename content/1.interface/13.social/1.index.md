Social publishing lets you write a post once and send it to several of your club's channels at the same time — a Facebook Page, an Instagram account, LinkedIn, X, Reddit, Telegram, Discord, Slack, or an app push notification to your members' phones.

Open **Club Admin → Social**. The area has two tabs:

- **Posts** — write and send posts, and see what happened to each one.
- **Channels** — connect and manage the social accounts you can publish to.

::note
You need the **Manage social** permission to use this area. A club admin grants it under **Settings → Roles**.
::

## Connect a channel first

Before you can publish anything, connect at least one channel on the **Channels** tab. See [Connecting channels](/interface/social/channels) for the steps for each platform.

## Write and send a post

1. On the **Posts** tab, select **New post**.
2. Write your **message**. This is the text of the post.
3. Add an optional **link**. Most platforms show a preview card for it.
4. Add an optional **image**. Instagram posts require an image; the other platforms treat it as optional.
5. Under **Publish to**, tick each channel that should receive the post. Only channels marked **Connected** appear here.
6. Fill in any per-channel fields that appear:
   - **Reddit** needs a post **title**. If the channel is a subreddit you connected with the SportyPlus app, the subreddit is fixed; otherwise, enter the target subreddit.
   - **App push notifications** need a **notification title** — the bold line shown on the phone. The message becomes the notification text and the link opens when a member taps it.
7. Select **Publish**.

### Character limits

Each platform has its own limit, and the editor shows a live counter for the tightest one among the channels you picked:

| Platform | Limit |
| --- | --- |
| X | 280 characters |
| Telegram | 4096 characters, or 1024 when an image is attached |
| Discord | 2000 characters |
| Slack | 3000 characters |
| App push notifications | 65 characters for the title, 240 for the message |

A link counts toward the limit. If the post is too long for a selected channel, **Publish** stays disabled until you shorten it or remove that channel.

## Track delivery

Each channel is delivered on its own, so one post can succeed on some channels and fail on others.

On the **Posts** tab, every post shows an overall status and a row of per-channel results:

| Status | Meaning |
| --- | --- |
| Publishing | The post is on its way. |
| Published | Delivered to every selected channel. |
| Partially failed | Delivered to some channels, failed on others. |
| Failed | Failed on every channel. |

For a delivered channel, the external-link icon opens the post on that platform. Telegram, Discord, and Slack channels connected with a webhook don't return a link, so there's nothing to open even though the post went through. App push notifications show how many devices they reached instead of a link.

### Retry a failed delivery

A failed channel shows a **Retry** button and an info icon with the platform's error message. Select **Retry** to send that channel again. Fix the cause first if the error points to one — for example, reconnect a channel that reports an authorization problem.

## What social publishing does not do (yet)

Scheduling, drafts, editing a post after it's sent, deleting a post from a platform, multiple images or video, and separate text per platform are not available. Each platform allows one connected account per club.
