The Leagues module runs any kind of organized competition — round-robin leagues, rating-based ladders, pyramids, American-format events, or elimination tournaments (see [Tournaments](/interface/tournaments)).

Manage leagues from **Club Admin → Leagues**.

![League list](/images/leagues-list.jpg)

## League types

When you create a league, pick the format that matches your competition:

| Type | Description |
| --- | --- |
| **Standard League** | Classic league with groups and a round-robin format |
| **Elo League** | Ranking based on an Elo rating system |
| **Padel League** | League for padel with pairs, tracking left/right positions |
| **Pyramid** | Pyramidal competition system, players challenge up the ladder |
| **Americanino** | American-format competition |
| **Cup / Tournament** | Elimination tournament played out as a bracket — see [Tournaments](/interface/tournaments) |

![League type selector](/images/leagues-type-selector.jpg)

## Running a league

Once a league is created you can manage it through its own tabs:

- **Groups** — organize players/teams into groups
- **Matches** — schedule and record match results
- **Standings** — automatically calculated rankings based on results

A league also has a status (Draft, Open, Active, Finished) that controls whether players can join and whether matches can be recorded.
