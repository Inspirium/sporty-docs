An AI agent is an assistant, such as [Claude Code](https://claude.com/claude-code), that can use tools on your behalf. Once you connect one to your club, you can ask it in plain language to do admin work, for example:

- *"Who asked to join this week? Approve the ones with an email at our school's domain."*
- *"Find Ana Horvat and tell me which memberships she has and when they end."*
- *"Make marija@example.com an administrator."*
- *"Change our phone number to +385 1 234 5678 and update the club description."*

The agent connects to SportyPlus through the **club MCP server**. MCP (Model Context Protocol) is the standard way AI assistants connect to other services.

You need to be a club [administrator](/en/interface/settings/administrators-and-roles).

## What the agent can do

The agent works on **one club**: the club you create the token for. It can:

- **Club profile**: read and change your club's name, description, contact details, address, map position, and whether the club is listed on [my.sporty.plus](https://my.sporty.plus).
- **Administrators**: list them, add someone by email (a person without an account is invited to register), and remove an administrator.
- **Members**: search members by name or email, see the memberships a member holds at your club, and remove someone from the club.
- **Join requests**: if your club checks new members before they can book, list the requests and approve or reject them.

It cannot see or change bookings, payments, prices or settings other than these. It cannot reach other clubs, even ones you also administer.

## How it stays safe

- **It acts as you.** The agent has your permissions at this club and no more. Everything it changes is recorded under your name.
- **It asks first.** The agent is told to check with you before it adds or removes an administrator, removes a member, or changes your public profile.
- **It stops when you do.** If you stop being an administrator of the club, the token stops working straight away.
- **It expires.** Every token has an expiry date, 90 days by default.
- **It can only use the agent server.** The token cannot sign in to the admin, the app or any other part of SportyPlus.

Treat a token like a password. Don't paste it into chats, emails or shared files. If it is lost or leaked, [revoke it](#revoke-a-token).

## Create a token

1. Open **Club Admin → Settings → AI agents**.
2. Under your club, choose **Create token**.
3. Give the token a name you will recognise later, such as *Laptop*, and choose how long it lasts.
4. Enter your SportyPlus password and choose **Create token** again.

The next screen shows the token and a ready-made command to connect Claude Code. **They are shown only once.** Copy them before you close the window. If you lose them, revoke the token and create a new one.

## Connect Claude Code

Paste the command from the token screen into a terminal. It looks like this:

```bash
claude mcp add --transport http sporty-club-123 https://api.sporty.plus/mcp/club \
  --header "Authorization: Bearer <token>"
```

Start a new Claude Code session and ask it about your club. Type `/mcp` to check that the connection says **connected**.

To make the connection available in every project, add `--scope user` after `claude mcp add`.

## Connect another AI assistant

Any assistant that supports remote MCP servers with a custom header works. Use:

- **Server URL:** `https://api.sporty.plus/mcp/club`
- **Header:** `Authorization: Bearer <token>`

Many assistants read a JSON configuration like this one. The exact file and format depend on the assistant, so check its documentation.

```json
{
  "mcpServers": {
    "sporty-club": {
      "type": "http",
      "url": "https://api.sporty.plus/mcp/club",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

## More than one club

A token belongs to one club. If you administer several clubs, switch to each club in the admin and create a token there. Give each connection its own name, such as `sporty-club-123` and `sporty-club-456`, so the assistant can tell them apart.

## Revoke a token

**Club Admin → Settings → AI agents** lists your tokens, with when each was created, last used and when it expires. Choose **Revoke** next to a token. It stops working immediately, and any agent using it loses access.

You see only your own tokens. Other administrators manage theirs.
