AI agent je asistent, kao što je [Claude Code](https://claude.com/claude-code), koji umjesto vas može koristiti alate. Kad ga povežete sa svojim klubom, možete ga običnim jezikom zamoliti za administratorske poslove, na primjer:

- *„Tko je ovaj tjedan zatražio učlanjenje? Odobri one s adresom na domeni naše škole.”*
- *„Pronađi Anu Horvat i reci mi koje članarine ima i kada istječu.”*
- *„Postavi marija@example.com za administratora.”*
- *„Promijeni naš broj telefona u +385 1 234 5678 i ažuriraj opis kluba.”*

Agent se sa SportyPlusom povezuje preko **klupskog MCP poslužitelja**. MCP (Model Context Protocol) standardni je način na koji se AI asistenti povezuju s drugim uslugama.

Morate biti [administrator](/hr/interface/settings/administrators-and-roles) kluba.

## Što agent može

Agent radi na **jednom klubu**: onom za koji ste izradili token. Može:

- **Profil kluba**: pročitati i promijeniti naziv kluba, opis, kontakt podatke, adresu, položaj na karti te je li klub naveden na [my.sporty.plus](https://my.sporty.plus).
- **Administratori**: ispisati ih, dodati nekoga putem e-pošte (osoba bez računa dobiva pozivnicu za registraciju) i ukloniti administratora.
- **Članovi**: pretraživati članove po imenu ili e-pošti, vidjeti članarine koje član ima u vašem klubu i ukloniti nekoga iz kluba.
- **Zahtjevi za učlanjenje**: ako vaš klub provjerava nove članove prije nego što mogu rezervirati, ispisati zahtjeve te ih odobriti ili odbiti.

Ne može vidjeti ni mijenjati rezervacije, plaćanja, cijene ni postavke osim navedenih. Ne može pristupiti drugim klubovima, čak ni onima kojima također upravljate.

## Kako ostaje siguran

- **Djeluje kao vi.** Agent u ovom klubu ima vaše ovlasti i ništa više. Sve što promijeni bilježi se pod vašim imenom.
- **Prvo pita.** Agent je upućen da vas pita prije nego što doda ili ukloni administratora, ukloni člana ili promijeni vaš javni profil.
- **Prestaje kad i vi.** Ako prestanete biti administrator kluba, token odmah prestaje raditi.
- **Istječe.** Svaki token ima datum isteka, prema zadanim postavkama 90 dana.
- **Radi samo s poslužiteljem za agente.** Tokenom se ne možete prijaviti u administraciju, aplikaciju ni bilo koji drugi dio SportyPlusa.

S tokenom postupajte kao s lozinkom. Ne lijepite ga u razgovore, e-poštu ni dijeljene datoteke. Ako ga izgubite ili procuri, [opozovite ga](#opozivanje-tokena).

## Izrada tokena

1. Otvorite **Club Admin → Postavke → AI agenti**.
2. Ispod svog kluba odaberite **Izradi token**.
3. Dajte tokenu naziv koji ćete kasnije prepoznati, primjerice *Laptop*, i odaberite koliko dugo vrijedi.
4. Unesite svoju SportyPlus lozinku i ponovno odaberite **Izradi token**.

Sljedeći zaslon prikazuje token i gotovu naredbu za povezivanje Claude Codea. **Prikazuju se samo jednom.** Kopirajte ih prije nego što zatvorite prozor. Ako ih izgubite, opozovite token i izradite novi.

## Povezivanje Claude Codea

Zalijepite naredbu sa zaslona tokena u terminal. Izgleda ovako:

```bash
claude mcp add --transport http sporty-club-123 https://api.sporty.plus/mcp/club \
  --header "Authorization: Bearer <token>"
```

Pokrenite novu Claude Code sesiju i pitajte ga nešto o svom klubu. Upišite `/mcp` kako biste provjerili piše li uz vezu **connected**.

Da bi veza bila dostupna u svim projektima, dodajte `--scope user` nakon `claude mcp add`.

## Povezivanje drugog AI asistenta

Radi svaki asistent koji podržava udaljene MCP poslužitelje s prilagođenim zaglavljem. Upotrijebite:

- **URL poslužitelja:** `https://api.sporty.plus/mcp/club`
- **Zaglavlje:** `Authorization: Bearer <token>`

Mnogi asistenti čitaju JSON konfiguraciju poput ove. Točna datoteka i oblik ovise o asistentu, pa provjerite njegovu dokumentaciju.

```json
{
  "mcpServers": {
    "sporty-club": {
      "type": "http",
      "url": "https://api.sporty.plus/mcp/club",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

## Više klubova

Token pripada jednom klubu. Ako upravljate s više klubova, u administraciji se prebacite na svaki klub i ondje izradite token. Svakoj vezi dajte vlastiti naziv, primjerice `sporty-club-123` i `sporty-club-456`, kako bi ih asistent razlikovao.

## Opozivanje tokena

**Club Admin → Postavke → AI agenti** prikazuje vaše tokene: kada je svaki izrađen, kada je zadnji put korišten i kada istječe. Odaberite **Opozovi** pokraj tokena. Odmah prestaje raditi i svaki agent koji ga koristi gubi pristup.

Vidite samo svoje tokene. Ostali administratori upravljaju svojima.
