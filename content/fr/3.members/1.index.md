Cette section s'adresse aux **membres et joueurs** d'un club qui utilise SportyPlus — réserver des courts, payer, jouer dans des ligues et gérer votre compte. Si vous gérez un club, consultez plutôt [Premiers pas](/fr/getting-started).

C'est votre club qui choisit les fonctionnalités qu'il utilise : une partie de ce qui est décrit ici peut donc ne pas apparaître dans l'application de votre club.

## Où trouver l'application

- **Sur le web :** l'adresse de votre club suivie de `/app/`, par exemple `https://yourclub.com/app/`. L'adresse qui regroupe tous les clubs est `https://my.sporty.plus/app/`.
- **Sur votre téléphone :** l'application **SportyPlus** pour [iPhone](https://apps.apple.com/hr/app/sportyplus/id1619337469) et [Android](https://play.google.com/store/apps/details?id=plus.tenis.app). La page de connexion web renvoie vers les deux sous **Inscrivez-vous via les applications mobiles**.

Lorsqu'une mise à jour est nécessaire, l'application affiche **Mettre à jour l'application.**

## Naviguer sans compte

Avant de vous connecter, vous pouvez généralement faire le tour : la page d'accueil, la liste des clubs, le calendrier des courts, les actualités, les résultats, les classements, les joueurs, les ligues et les tournois. Votre club peut désactiver cette option ; dans ce cas, vous arrivez directement sur la page de connexion.

Toute action — réserver, rejoindre, payer, envoyer un message — vous demande d'abord de vous connecter ou de vous inscrire. Une fois connecté, l'application reprend là où vous en étiez.

## Créer un compte

Sur la page de connexion, ouvrez l'onglet **Inscription** (ou choisissez **S'inscrire** dans la fenêtre d'inscription) et remplissez :

- **Prénom** et **Nom**, **Sexe** (Femme, Homme ou Autre), **Adresse e-mail**, **Date de naissance**, **Pays** (votre pays), et un **Mot de passe** d'au moins 8 caractères, à saisir deux fois.
- Facultativement, votre **Numéro de téléphone mobile** et votre **Lieu** (ville ou commune).
- Acceptez les conditions d'utilisation de SportyPlus, ainsi que celles de votre club s'il en a.

Choisissez **S'inscrire** : vous êtes connecté immédiatement.

Vous pouvez aussi continuer avec **Apple**, **Google** ou **Microsoft**, et dans certaines applications avec **DUPR**. La première fois, l'application vous demande de compléter votre profil (**Complétez votre profil**) avec votre date de naissance, votre sexe et votre pays.

### Membres de moins de 16 ans

Une personne de moins de 16 ans a besoin de l'autorisation d'un parent ou d'un tuteur. Le formulaire d'inscription demande un **E-mail du parent ou tuteur** ; nous lui envoyons un lien par e-mail, et le compte peut être utilisé dès qu'il l'a approuvé. D'ici là, la connexion affiche **En attente de votre parent ou tuteur**, avec la possibilité de renvoyer l'e-mail ou de l'envoyer à un autre tuteur. Les parents peuvent aussi créer et gérer eux-mêmes le profil d'un enfant — voir [Famille et enfants](/fr/members/family).

### Essayez d'abord

Dans les applications mobiles et sur my.sporty.plus, **Essayer le club de démo** ouvre un club de démonstration sans inscription. Tout y est réinitialisé chaque nuit.

## Rejoindre un club

S'inscrire n'est pas la même chose qu'être membre d'un club. Sur la page d'accueil de votre club :

- Si le club accepte tout le monde, choisissez **Rejoindre le club** (le bouton peut indiquer **Inscrivez-vous**). Vous pouvez réserver immédiatement.
- Si le club approuve les nouveaux membres, ouvrez la page du club et choisissez **Envoyer une demande d'adhésion**. L'équipe du club vous accepte ; d'ici là, certaines pages du club restent masquées.
- Si le club exige une adhésion payante avant toute réservation, la page d'accueil affiche **Achetez un abonnement** — voir [Adhésions et paiements](/fr/members/payments).

## Changer de club

Vous pouvez être membre de plusieurs clubs. Ouvrez le menu et choisissez l'un de **Vos clubs**, ou choisissez **Trouver un club...** pour chercher dans la liste ou sur la carte. Dans les applications mobiles, l'application change de club sur place ; sur le web, vous êtes redirigé vers l'adresse propre à ce club.

Pour quitter un club, touchez le **×** à côté de son nom dans le menu, ou allez dans **Modifier le profil** → **Liste des clubs dont vous êtes membre** → **Se désinscrire**.

## Se repérer

- Le **menu** (en haut à gauche) liste les rubriques du club : **Réservation d'un terrain**, **Joueurs**, **Entraîneurs**, **Résultats**, **Ligues**, **Tournois**, **Nouvelles**, **A propos du club** et les autres rubriques activées par votre club.
- **Votre photo** (en haut à droite) ouvre votre menu personnel : **Modifier le profil**, **Mon profil**, **Mes réservations**, **Mes commandes**, **Ma famille**, **Comptes associés**, **Connexion et sécurité**, **Notifications**, **Messages**, **Signaler un problème** et **Se déconnecter**.
- La **page d'accueil** affiche les widgets choisis par votre club, comme votre prochaine réservation, votre adhésion, le solde de votre porte-monnaie et les compétitions à venir. Toucher le nom du club en haut vous ramène toujours à l'accueil.

## Obtenir de l'aide

- **Un problème au club** — une lumière éteinte sur un court, un distributeur vide, un remboursement — ou **un problème avec l'application** : utilisez **Signaler un problème**. Voir [Obtenir de l'aide](/fr/members/help).
- **Une question sur le règlement ou les tarifs de votre club** : c'est votre club qui les fixe ; **A propos du club** affiche ses coordonnées, ses courts, ses adhésions et ses règles de réservation.
- **Une question sur SportyPlus lui-même** : écrivez à [info@sporty.plus](mailto:info@sporty.plus).
