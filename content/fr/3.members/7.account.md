Votre compte SportyPlus est un compte unique pour tous les clubs : les mêmes identifiants fonctionnent partout.

## Modifier votre profil

Menu de votre photo → **Modifier le profil**. Vous pouvez changer votre photo, votre nom, votre adresse e-mail, votre sexe, votre date de naissance, votre pays, votre ville, votre adresse et votre numéro de téléphone. **Enregistrer les modifications** apparaît dès que vous avez modifié quelque chose.

Changez la langue de l'application depuis le drapeau dans le menu (**Changer de langue**), ou sur la page de connexion.

## Connexion et mots de passe

- **Mot de passe oublié ?** sur la page de connexion vous envoie par e-mail un lien pour en définir un nouveau. Vérifiez votre dossier de courrier indésirable s'il n'arrive pas.
- Pour changer votre mot de passe une fois connecté : **Modifier le profil** → **Changer le mot de passe**.
- Si vous vous êtes inscrit avec Apple, Google ou Microsoft et n'avez pas encore de mot de passe, **Comptes associés** propose **Définir un mot de passe**.

### Clés d'accès

Une clé d'accès (passkey) vous permet de vous connecter avec votre empreinte digitale, votre visage ou le code PIN de votre appareil au lieu d'un mot de passe. Ajoutez-en une depuis le menu de votre photo → **Connexion et sécurité** → **Clés d'accès** → **Ajouter une clé d'accès**. **Se connecter avec une clé d'accès** est disponible dans les applications mobiles et sur my.sporty.plus ; sur l'adresse web propre à un club, l'application vous redirige vers my.sporty.plus pour en ajouter une.

### Connexion à deux facteurs

Sous **Connexion et sécurité** → **Application d'authentification** → **Configurer**, scannez le code avec une application d'authentification, saisissez le code et choisissez **Activer**. Conservez les codes de récupération affichés. Désormais, l'application vous demande un code après votre mot de passe ; si vous n'avez pas votre téléphone, utilisez **Utiliser un code de récupération**.

### Se déconnecter

Menu de votre photo → **Se déconnecter**.

## Comptes associés

Menu de votre photo → **Comptes associés** affiche :

- les comptes Apple, Google ou Microsoft avec lesquels vous pouvez vous connecter — **Associer** ou **Dissocier** ;
- votre compte [DUPR](/fr/members/competitions#dupr) ;
- votre [carte enregistrée](/fr/members/payments#carte-enregistrée).

## Notifications

**Notifications** → **Modifier** vous permet d'activer ou de désactiver chaque type de notification, séparément pour les notifications push et les e-mails, et club par club. **Rétablir les valeurs par défaut** annule vos modifications. Les factures, les demandes de paiement et les réinitialisations de mot de passe sont toujours envoyées par e-mail.

## Confidentialité

**Modifier le profil** → **Paramètres de confidentialité** détermine si votre profil est public et si les autres peuvent voir votre nom, votre adresse e-mail, votre téléphone et votre date de naissance. Réglez-les pour tous les clubs, ou utilisez **Personnaliser pour ce club**.

## Quitter un club

Touchez le **×** à côté du club dans le menu, ou allez dans **Modifier le profil** → **Liste des clubs dont vous êtes membre** → **Se désinscrire**. Votre compte est conservé ; vous n'êtes simplement plus membre de ce club.

## Supprimer votre compte

**Modifier le profil** → **Supprimer définitivement le profil**, puis confirmez. Cela supprime votre profil SportyPlus pour tous les clubs.
