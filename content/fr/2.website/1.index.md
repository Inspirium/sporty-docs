Chaque club SportyPlus dispose d'un site web public construit à partir de modules de contenu — Hero, Pages, Actualités, Événements, Entraîneurs, Galerie, et bien d'autres. Activez ou désactivez les modules, réorganisez-les et modifiez leur contenu sans toucher au code.

Gérez votre site depuis l'onglet **Site web** du sélecteur de la barre latérale de l'administration (à côté de **Club Admin** et **Super admin**).

## Modules

**Site web → Modules** vous permet de choisir les sections affichées sur votre page d'accueil, et dans quel ordre. Faites glisser les modules actifs pour les réorganiser, ou ajoutez-en un depuis la liste des modules inactifs à droite.

![Gestionnaire des modules du site web](/images/website-modules.jpg)

Chaque module (Boutique, Courts, Fonctionnalités, Événements, Galerie, Vidéo, Adhésions, Actualités, Entraîneurs, FAQ, CTA...) dispose aussi de sa propre page de paramètres, où vous l'activez indépendamment et modifiez son contenu — voir les pages ci-dessous.

## Navigation

**Site web → Navigation** contrôle les liens affichés dans le menu principal de votre site. Ajoutez au menu n'importe quel module de contenu ou page publiée, et réorganisez les éléments par glisser-déposer.

![Éditeur de navigation du site web](/images/website-navigation.jpg)

## Styles

**Site web → Styles** vous permet de personnaliser le thème visuel de votre site public — couleurs et identité visuelle — sans modifier de code.
