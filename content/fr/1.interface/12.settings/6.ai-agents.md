Un agent IA est un assistant, comme [Claude Code](https://claude.com/claude-code), qui peut utiliser des outils à votre place. Une fois connecté à votre club, vous pouvez lui confier des tâches d'administration en langage courant, par exemple :

- *« Qui a demandé à rejoindre le club cette semaine ? Accepte ceux dont l'adresse est sur le domaine de notre école. »*
- *« Trouve Ana Horvat et dis-moi quels abonnements elle a et quand ils se terminent. »*
- *« Nomme marija@example.com administratrice. »*
- *« Change notre numéro de téléphone en +385 1 234 5678 et mets à jour la description du club. »*

L'agent se connecte à SportyPlus par le **serveur MCP de club**. MCP (Model Context Protocol) est la façon standard dont les assistants IA se connectent à d'autres services.

Vous devez être [administrateur](/fr/interface/settings/administrators-and-roles) du club.

## Ce que l'agent peut faire

L'agent travaille sur **un seul club** : celui pour lequel vous créez le jeton. Il peut :

- **Profil du club** : lire et modifier le nom, la description, les coordonnées, l'adresse et la position sur la carte du club, et choisir s'il figure sur [my.sporty.plus](https://my.sporty.plus).
- **Administrateurs** : les lister, ajouter quelqu'un par e-mail (une personne sans compte est invitée à s'inscrire) et retirer un administrateur.
- **Membres** : rechercher des membres par nom ou e-mail, voir les abonnements d'un membre dans votre club et retirer quelqu'un du club.
- **Demandes d'adhésion** : si votre club vérifie les nouveaux membres avant qu'ils puissent réserver, lister les demandes et les accepter ou les refuser.

Il ne peut ni voir ni modifier les réservations, les paiements, les prix ou d'autres paramètres que ceux-ci. Il ne peut pas accéder à d'autres clubs, même à ceux que vous administrez aussi.

## Comment il reste sûr

- **Il agit en votre nom.** L'agent a vos droits dans ce club, et rien de plus. Tout ce qu'il modifie est enregistré à votre nom.
- **Il demande d'abord.** L'agent doit vous consulter avant d'ajouter ou de retirer un administrateur, de retirer un membre ou de modifier votre profil public.
- **Il s'arrête en même temps que vous.** Si vous n'êtes plus administrateur du club, le jeton cesse immédiatement de fonctionner.
- **Il expire.** Chaque jeton a une date d'expiration, 90 jours par défaut.
- **Il ne sert qu'au serveur pour agents.** Le jeton ne permet pas de se connecter à l'administration, à l'application ni à aucune autre partie de SportyPlus.

Traitez un jeton comme un mot de passe. Ne le collez pas dans des conversations, des e-mails ou des fichiers partagés. S'il est perdu ou divulgué, [révoquez-le](#révoquer-un-jeton).

## Créer un jeton

1. Ouvrez **Club Admin → Paramètres → Agents IA**.
2. Sous votre club, choisissez **Créer un jeton**.
3. Donnez au jeton un nom que vous reconnaîtrez plus tard, par exemple *Portable*, et choisissez sa durée de validité.
4. Saisissez votre mot de passe SportyPlus et choisissez de nouveau **Créer un jeton**.

L'écran suivant affiche le jeton et une commande toute prête pour connecter Claude Code. **Ils ne sont affichés qu'une seule fois.** Copiez-les avant de fermer la fenêtre. Si vous les perdez, révoquez le jeton et créez-en un nouveau.

## Connecter Claude Code

Collez la commande de l'écran du jeton dans un terminal. Elle ressemble à ceci :

```bash
claude mcp add --transport http sporty-club-123 https://api.sporty.plus/mcp/club \
  --header "Authorization: Bearer <token>"
```

Ouvrez une nouvelle session Claude Code et posez-lui une question sur votre club. Tapez `/mcp` pour vérifier que la connexion indique **connected**.

Pour que la connexion soit disponible dans tous vos projets, ajoutez `--scope user` après `claude mcp add`.

## Connecter un autre assistant IA

Tout assistant qui prend en charge les serveurs MCP distants avec un en-tête personnalisé fonctionne. Utilisez :

- **URL du serveur :** `https://api.sporty.plus/mcp/club`
- **En-tête :** `Authorization: Bearer <token>`

De nombreux assistants lisent une configuration JSON comme celle-ci. Le fichier et le format exacts dépendent de l'assistant : consultez sa documentation.

```json
{
  "mcpServers": {
    "sporty-club": {
      "type": "http",
      "url": "https://api.sporty.plus/mcp/club",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

## Plusieurs clubs

Un jeton appartient à un seul club. Si vous administrez plusieurs clubs, passez à chaque club dans l'administration et créez-y un jeton. Donnez à chaque connexion son propre nom, par exemple `sporty-club-123` et `sporty-club-456`, pour que l'assistant puisse les distinguer.

## Révoquer un jeton

**Club Admin → Paramètres → Agents IA** liste vos jetons, avec leur date de création, leur dernière utilisation et leur date d'expiration. Choisissez **Révoquer** à côté d'un jeton. Il cesse immédiatement de fonctionner, et tout agent qui l'utilise perd l'accès.

Vous ne voyez que vos propres jetons. Les autres administrateurs gèrent les leurs.
