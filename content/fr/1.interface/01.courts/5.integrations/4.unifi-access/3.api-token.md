SportyPlus agit sur vos portes grâce à un **jeton d'API** issu d'UniFi Access. Vous le créez
vous-même sur votre console et le collez dans Club Admin : il n'a donc jamais besoin d'être envoyé
à qui que ce soit.

## Créer le jeton

Connectez-vous à votre console, sur [unifi.ui.com](https://unifi.ui.com) ou à son adresse locale,
et ouvrez **UniFi Access** :

1. Ouvrez **Settings → General → Advanced → API Token**, puis choisissez **Create New**.
2. Nommez-le `SportyPlus`, pour que l'on sache clairement à quoi il correspond dans le journal de
   la console.
3. Définissez la **validité** aussi longue que vous le jugez acceptable. Quand le jeton expire,
   SportyPlus cesse d'émettre des codes PIN et ne peut plus déverrouiller les portes tant que vous
   n'en avez pas collé un nouveau.
4. Sélectionnez les autorisations ci-dessous, puis créez le jeton.
5. **Copiez le jeton tout de suite.** UniFi ne l'affiche qu'une seule fois.

## Autorisations

UniFi les appelle des « permission scopes » et les regroupe par domaine. Sélectionnez ces trois-ci :

| Scope | Utilisation par SportyPlus |
| --- | --- |
| `view:space` | lire vos portes, pour que vous puissiez les associer aux courts |
| `edit:space` | déverrouiller une porte lorsque le personnel appuie sur **Déverrouiller** dans Club Admin |
| `edit:visitor` | créer pour chaque joueur ayant réservé un visiteur avec son code PIN, et le faire passer d'une réservation à l'autre |

::warning
Une autorisation manquante ne se remarque pas lors de la création du jeton. Elle se manifeste plus
tard, lorsque la console refuse une requête. Si les codes PIN de porte n'apparaissent pas, ou si
**Déverrouiller** échoue avec *refused (403)*, vérifiez d'abord ces autorisations.
::

N'accordez rien d'autre au jeton. Il n'a besoin ni des utilisateurs, ni des politiques d'accès, ni
des paramètres système.

## Étape suivante

Collez le jeton dans Club Admin :
[configurer dans Club Admin](/fr/interface/courts/integrations/unifi-access/club-admin).

Si vous pensez que le jeton a fuité, supprimez-le dans UniFi Access, créez-en un nouveau et
collez-le. L'ancien cesse immédiatement de fonctionner.
