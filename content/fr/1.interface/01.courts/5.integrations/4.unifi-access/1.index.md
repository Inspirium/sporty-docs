Si les portes de votre club fonctionnent avec **UniFi Access** (le système de contrôle d'accès
d'Ubiquiti), SportyPlus peut les piloter à partir de vos réservations :

- chaque joueur d'une **réservation payée** reçoit un **code PIN de porte** qui ne fonctionne que
  sur les portes menant à son court, et seulement autour de l'heure réservée
- le personnel du club peut **déverrouiller une porte** depuis Club Admin
- une porte d'entrée peut desservir **tous les courts**, pour que toute personne ayant une
  réservation puisse la franchir

Le code PIN est le **code d'accès** du membre : le même code que votre club affiche déjà dans
l'application et dans les e-mails de rappel de réservation. Les membres n'ont pas à retenir un
nouveau code à chaque réservation.

## Ce dont vous avez besoin

- Une console UniFi exécutant **UniFi Access**, comme un UDM-Pro ou un Cloud Key, avec vos hubs
  de porte et lecteurs adoptés et fonctionnels. SportyPlus a été testé avec UniFi OS 5.1, UniFi
  Access 4.3 et UniFi Network 10.6.
- Un **accès propriétaire ou administrateur** à cette console, à la fois pour configurer un client
  VPN dans UniFi Network et pour créer un jeton d'API dans UniFi Access.
- Un lecteur à clavier qui accepte les codes PIN, comme un G3 Intercom ou un G2/G3 Reader Pro, sur
  chaque porte que les membres doivent ouvrir avec un code.

## Comment l'ensemble s'articule

UniFi Access ne répond que sur le réseau de votre club. Le cloud d'Ubiquiti ne relaie pas ces
échanges, si bien que SportyPlus ne peut pas l'atteindre par Internet comme il atteint Shelly
Cloud. À la place, **votre console ouvre un petit tunnel VPN vers SportyPlus** :

1. Votre console se connecte vers SportyPlus avec **WireGuard**. Rien n'est ouvert sur votre
   routeur, et cela fonctionne même lorsque la console se trouve derrière un autre routeur, ce qui
   est fréquent.
2. Par ce tunnel, SportyPlus communique avec UniFi Access sur votre console, et avec rien d'autre
   sur votre réseau. La règle de pare-feu de votre console n'autorise que ce seul port.
3. Vous fournissez à SportyPlus un **jeton d'API** issu d'UniFi Access. Il permet à SportyPlus de
   lire vos portes, d'ajouter des visiteurs avec leur code PIN et de déverrouiller les portes.
4. Dans Club Admin, vous connectez la console, associez chaque porte aux courts qu'elle dessert et
   activez les codes PIN de porte.

Votre console applique elle-même chaque code PIN : un membre entre donc avec son code même si votre
connexion Internet, ou la nôtre, est coupée à son arrivée.

## Mise en place

Suivez ces étapes dans l'ordre. Chacune nécessite la précédente.

1. [**Connecter le VPN**](/fr/interface/courts/integrations/unifi-access/vpn) : téléchargez le
   fichier WireGuard de votre club depuis Club Admin, importez-le sur la console et autorisez
   SportyPlus dans son pare-feu.
2. [**Créer un jeton d'API**](/fr/interface/courts/integrations/unifi-access/api-token) dans UniFi Access.
3. [**Configurer dans Club Admin**](/fr/interface/courts/integrations/unifi-access/club-admin) :
   l'adresse de la console, le jeton, vos portes et vos courts, et les codes PIN de porte.

::note
Vous n'avez pas besoin de nous contacter pour tout cela. Club Admin crée le fichier VPN et
l'adresse de tunnel de votre club, et le côté SportyPlus du tunnel se configure tout seul en moins
d'une minute.
::
