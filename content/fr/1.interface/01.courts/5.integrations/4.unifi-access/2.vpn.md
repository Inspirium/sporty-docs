Votre console se connecte **vers l'extérieur**, à SportyPlus, via WireGuard. Vous n'avez aucun
port à rediriger ni aucun réglage à modifier sur votre box Internet. Cela fonctionne même lorsque
la console se trouve derrière un autre routeur, comme c'est souvent le cas quand le fournisseur
d'accès fournit le routeur principal.

Cette page comporte trois étapes : télécharger le fichier de votre club depuis Club Admin,
l'importer sur la console, et ajouter une règle de pare-feu. Le réseau de votre club reste tel
quel : nous n'y routons jamais rien, peu importe donc la plage d'adresses qu'il utilise, ou qu'un
autre club utilise la même.

## 1. Télécharger le fichier WireGuard de votre club

Dans **Club Admin → Entreprise → Intégrations → UniFi Access**, appuyez sur **Créer une connexion
VPN** sous **Connexion VPN**. Votre navigateur télécharge un fichier de configuration WireGuard
(`.conf`) créé pour votre club, et la carte affiche l'**adresse de tunnel** de votre console, par
exemple `10.200.0.3`. L'adresse de la console, plus bas sur la page, est remplie automatiquement
avec celle-ci.

Le fichier contient la clé privée de votre club : **traitez-le comme un mot de passe**, ne le
transférez pas et ne le publiez nulle part. SportyPlus n'en conserve pas de copie, vous ne pouvez
donc le télécharger qu'une seule fois. Si vous le perdez, appuyez sur **Télécharger un nouveau
fichier**. De nouvelles clés sont alors émises, et l'ancien fichier cesse de fonctionner en moins
d'une minute.

Le fichier ne fait passer par le tunnel que le trafic destiné à l'adresse de tunnel de SportyPlus.
Le reste du trafic Internet de votre club continue de sortir comme aujourd'hui.

## 2. L'importer sur la console

Dans **UniFi Network** sur votre console :

1. Ouvrez **Settings → VPN → VPN Client**, puis choisissez **Create New**.
2. Choisissez **WireGuard** comme type et donnez-lui un nom, par exemple `SportyPlus`.
3. Téléversez le fichier `.conf` que nous vous avons envoyé, ou collez son contenu.
4. Enregistrez, et vérifiez que le client est activé.

**Ne créez pas** de route de trafic ni de route de stratégie (policy route) pour ce client.
SportyPlus n'a besoin de faire passer aucune partie de votre trafic par ce client.

::warning
**"Invalid DNS in [Interface]. Use: DNS = IP Address"** : UniFi refuse d'importer un fichier
WireGuard sans ligne `DNS`, même si ce tunnel n'en utilise pas. Les fichiers que nous envoyons
contiennent déjà `DNS = 1.1.1.1`. Si ce message s'affiche, le fichier a été modifié ou il s'agit
d'un ancien fichier. Ajoutez la ligne `DNS = 1.1.1.1` sous `[Interface]` et téléversez-le à
nouveau, ou demandez-nous un nouveau fichier. Un nom d'hôte ou une valeur vide est refusé de la
même manière.
::

Une fois enregistré, la console se connecte en une à deux minutes. La carte **Connexion VPN** dans
Club Admin affiche alors **Connecté** ainsi que l'heure du dernier contact de la console. Appuyez
sur **Vérifier à nouveau** pour l'actualiser.

## 3. Autoriser SportyPlus à accéder à UniFi Access

Par défaut, la console bloque le trafic arrivant par un client VPN : cette règle est donc
indispensable. Sans elle, SportyPlus indique qu'il **n'a pas pu joindre la console**.

Dans **UniFi Network → Settings → Security → Firewall**, ajoutez une règle :

| Paramètre | Valeur |
| --- | --- |
| Action | **Allow** |
| Source | le client VPN WireGuard **SportyPlus**, adresse `10.200.0.1` |
| Destination | la console elle-même (**Gateway**) |
| Protocole / port | **TCP 12445** uniquement |

Le port **12445** est celui de l'API d'UniFi Access. N'autorisez rien de plus : SportyPlus n'a
besoin de rien d'autre sur votre réseau.

::note
Les écrans du pare-feu varient selon les versions d'UniFi Network. Sur les versions récentes, les
règles se définissent entre **zones** : autorisez de la zone VPN vers la zone Gateway. Quel que
soit l'écran, la règle reste la même : depuis `10.200.0.1`, vers la console elle-même, TCP 12445,
autoriser.
::

## Une fois terminé

Dès que la carte affiche **Connecté** et que la règle est en place,
[créez le jeton d'API](/fr/interface/courts/integrations/unifi-access/api-token).
