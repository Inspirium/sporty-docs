Tout ce qui concerne UniFi Access se trouve sur une seule page : **Club Admin → Entreprise →
Intégrations → UniFi Access** (`/admin/app/business/integrations/unifi-access`). Vous devez être
administrateur du club.

Avant de commencer, le [VPN](/fr/interface/courts/integrations/unifi-access/vpn) doit être connecté
et vous devez disposer d'un [jeton d'API](/fr/interface/courts/integrations/unifi-access/api-token).

## Connexion VPN

La première carte crée le tunnel entre votre console et SportyPlus : **Créer une connexion VPN**
télécharge le fichier que vous importez sur la console (voir [Connecter le VPN](/fr/interface/courts/integrations/unifi-access/vpn)).
Ensuite, la carte affiche :

- l'**adresse de tunnel** de votre console, qui est aussi l'adresse de la console ci-dessous
- **Connecté** ou **En attente de la console**, ainsi que l'heure du dernier contact de la console
- **Télécharger un nouveau fichier**, en cas de fichier perdu ou de nouvelle console. De nouvelles
  clés et une nouvelle adresse de tunnel sont émises, et l'adresse de la console est mise à jour en
  conséquence.
- **Supprimer la connexion VPN**, qui coupe le tunnel en moins d'une minute. Les codes PIN de porte
  et le déverrouillage cessent de fonctionner jusqu'à ce que vous en créiez une nouvelle.

## Console

| Champ | À saisir |
| --- | --- |
| **Actif** | activé |
| **Adresse de la console** | `https://` + l'**adresse de tunnel** de votre console + `:12445`, par exemple `https://10.200.0.3:12445`. La création de la connexion VPN remplit ce champ. |
| **Jeton d'API** | le jeton que vous avez copié depuis UniFi Access |

Appuyez sur **Sauvegarder**.

Utilisez l'adresse de tunnel, et non l'adresse de la console sur le réseau de votre club. Elle est
propre à votre club et n'entre donc jamais en conflit avec le réseau d'un autre club. L'adresse
doit être en `https`, être une adresse de réseau privé et utiliser le port `12445` ; toute autre
valeur est refusée à l'enregistrement. C'est voulu : SportyPlus ne communique jamais avec une
console autrement que par votre tunnel.

Le jeton ne peut plus être relu une fois enregistré. Le champ affiche **Enregistré. Laissez vide
pour le conserver.** Laissez-le vide pour conserver le jeton enregistré, ou collez-en un nouveau
pour le remplacer.

## Portes

Appuyez sur **Lire les portes depuis la console**. SportyPlus liste toutes les portes de votre
console, avec leur nom et leur emplacement complet, et indique quand les portes ont été lues pour
la dernière fois.

Pour chaque porte, choisissez les **Terrains** qu'elle dessert :

- un ou plusieurs courts, pour une porte qui ne mène qu'à ces courts
- **Tous les courts**, pour une porte par laquelle passe chaque réservation, comme l'entrée du
  bâtiment. Ce choix efface les courts sélectionnés individuellement, et choisir un court efface
  **Tous les courts**.
- rien, pour une porte à laquelle SportyPlus ne doit jamais donner accès, comme un bureau ou une
  réserve

Appuyez sur **Sauvegarder** en bas de la liste pour conserver les courts choisis.

Relire les portes plus tard conserve les courts déjà définis. Une porte supprimée de la console
disparaît de la liste, avec ses courts.

## Déverrouiller une porte

Chaque porte dispose d'un bouton **Déverrouiller**. Il ouvre la porte **une fois, immédiatement**,
pour la personne qui s'y trouve. Une confirmation vous est d'abord demandée.

Le journal de la console enregistre le déverrouillage sous votre nom, précédé de `SportyPlus:`, ce
qui vous permet de toujours savoir qui a ouvert une porte depuis Club Admin. La limite est de
quelques déverrouillages par minute.

## Codes PIN de porte

C'est dans cette section que les réservations se transforment en accès aux portes.

| Paramètre | Effet | Par défaut |
| --- | --- | --- |
| **Émettre des codes PIN de porte pour les réservations** | active les codes PIN de porte pour votre club | **désactivé** |
| **Minutes avant la réservation** | combien de temps à l'avance un code PIN commence à fonctionner | 15 |
| **Minutes après la réservation** | combien de temps il continue de fonctionner après la fin de la réservation | 15 |
| **Longueur du code PIN** | la longueur des nouveaux codes PIN, qui doit correspondre à celle définie sur votre console | 6 |

Rien ne se passe tant que vous n'avez pas activé **Émettre des codes PIN de porte pour les
réservations** et enregistré. Vous pouvez donc d'abord connecter la console et associer les portes,
puis activer les codes PIN quand vous êtes prêt, idéalement avec quelqu'un au club pour tester une
porte.

### Ce que reçoivent les membres

Une fois les codes PIN activés, dans la minute qui suit le paiement d'une réservation :

- **chaque joueur et chaque entraîneur** de la réservation peut entrer avec son propre code PIN.
  Les personnes qui ne font que suivre une réservation n'en reçoivent pas.
- le code PIN fonctionne sur les portes qui desservent le court réservé, ainsi que sur toute porte
  **Tous les courts**
- du nombre de minutes choisi avant le début de la réservation jusqu'au nombre de minutes choisi
  après sa fin

Le code PIN d'un membre est son **code d'accès**, déjà affiché dans l'application et dans les
e-mails de rappel de réservation. Il reste le même d'une réservation à l'autre. Un membre qui a
déjà un code d'accès issu de Weblock conserve ce code. Sinon, SportyPlus en crée un de la longueur
de code PIN que vous avez définie.

Une réservation **encore en attente de paiement** ne donne aucun accès tant qu'elle n'est pas
payée. Une réservation **annulée** cesse de fonctionner en moins d'une minute.

### Ce que vous voyez sur la console

Chaque membre apparaît dans UniFi Access comme **un seul visiteur**, à son nom, portant son code
PIN. SportyPlus fait passer ce visiteur d'une réservation à l'autre : une fois l'heure d'une
réservation passée, les horaires et les portes du visiteur sont remplacés par ceux de la
réservation suivante du membre. Deux réservations qui se suivent forment une seule plage continue,
pour que le membre ne se retrouve pas bloqué entre les deux. Quand un membre n'a plus rien de
réservé, son visiteur est supprimé, mais il garde son code PIN pour la prochaine fois.

Ne modifiez pas ces visiteurs sur la console. SportyPlus les corrige en moins d'une minute.

::note
Désactiver **Émettre des codes PIN de porte pour les réservations** empêche SportyPlus de créer ou
de modifier des visiteurs, mais ne supprime pas ceux qui se trouvent déjà sur la console.
Supprimez-les dans UniFi Access si l'accès doit cesser immédiatement.
::

## En cas de problème

SportyPlus affiche la réponse de la console lorsqu'une action échoue.

| Message | Signification |
| --- | --- |
| *The UniFi Access console could not be reached* | le VPN est coupé, ou la [règle de pare-feu](/fr/interface/courts/integrations/unifi-access/vpn#_3-autoriser-sportyplus-à-accéder-à-unifi-access) est manquante. Vérifiez que le client VPN SportyPlus est activé. |
| *refused the request (401)* | le jeton d'API est erroné ou a expiré. Créez-en un nouveau et collez-le. |
| *refused the request (403)* | il manque une [autorisation](/fr/interface/courts/integrations/unifi-access/api-token#autorisations) au jeton |
| *The console address … is not allowed* | l'adresse n'est pas de la forme `https://10.200.0.x:12445` |
| *UniFi Access is not set up for this club* | enregistrez d'abord l'adresse de la console et le jeton |

Si le code PIN d'un membre n'ouvre pas une porte, vérifiez que la réservation est payée, que son
court est associé à cette porte, et que **Émettre des codes PIN de porte pour les réservations**
est activé. Une console qui était hors ligne se met à jour d'elle-même dans la minute qui suit son
retour en ligne.
