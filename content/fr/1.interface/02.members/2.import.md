Quand votre club passe à SportyPlus depuis un autre système, vous n'avez pas à tout ressaisir. Exportez la liste des membres et les réservations fixes de l'ancien système sous forme de tableur, puis importez-les ici.

Les deux imports se font en deux étapes. D'abord, vous chargez le fichier et voyez ce qui arriverait à chaque ligne. Rien n'est enregistré à ce stade : vous pouvez corriger le fichier et le recharger autant de fois que nécessaire. Ensuite, vous lancez l'import.

Importez d'abord vos membres. Une réservation appartient à un membre, donc l'import des réservations ne trouve que les personnes déjà membres de votre club.

## Importer des membres

Allez dans **Club Admin → Communauté → Membres → Importer des membres**, ou choisissez **Importer** sur la liste des membres.

1. Exportez la liste des membres de l'ancien système en CSV ou Excel (XLSX, XLS et ODS fonctionnent aussi). Un fichier peut contenir jusqu'à 5 000 membres.
2. Déposez le fichier sur la page. L'aperçu s'ouvre.
3. Vérifiez les lignes marquées **À corriger**, corrigez-les dans le fichier et rechargez-le.
4. Décidez si les nouveaux membres doivent recevoir un e-mail expliquant comment se connecter (voir [Prévenir les membres](#prévenir-les-membres)).
5. Choisissez **Importer**.

### Les colonnes

La première ligne du fichier doit nommer les colonnes. SportyPlus reconnaît les noms habituels, en anglais, en croate et en slovène, donc l'export de votre ancien système fonctionne généralement tel quel. Les colonnes inconnues sont ignorées. **Télécharger le modèle** vous donne un fichier vide avec toutes les colonnes.

| Colonne | Contenu | Aussi reconnue comme |
| --- | --- | --- |
| `first_name` | Obligatoire | First name, Ime |
| `last_name` | Obligatoire | Last name, Surname, Prezime, Priimek |
| `email` | L'e-mail du membre. Laissez vide pour un junior qui utilise l'e-mail d'un parent. | E-mail, Mail |
| `gender` | M, F ou O ; aussi Male/Female et les mots croates et slovènes | Sex, Spol |
| `birth_date` | Date de naissance. Obligatoire pour un junior sans e-mail. | Date of birth, DOB |
| `country` | Code à deux lettres (FR) ou nom du pays. Vide signifie le pays de votre club. | Country |
| `phone` | Numéro de téléphone | Mobile, Telefon |
| `guardian_email` | L'e-mail du parent ou tuteur du junior | Parent email |
| `membership` | Le nom d'une des adhésions de votre club | Membership type |
| `membership_start` | Date de début de l'adhésion. Vide signifie aujourd'hui. | Start date, Valid from |
| `membership_end` | Date de fin de l'adhésion | End date, Expires, Valid until |
| `balance` | Le crédit prépayé que le membre a encore au club | Wallet, Credit |

Les dates peuvent s'écrire 2026-12-31, 31.12.2026 ou 31/12/2026, ou être de vraies dates dans le tableur. Les montants peuvent utiliser une virgule ou un point pour les décimales, et le symbole monétaire est ignoré.

### Ce qui arrive à chaque ligne

L'aperçu affiche l'un des cas suivants pour chaque ligne :

- **Nouveau compte** — un nouveau compte SportyPlus est créé et rejoint votre club.
- **A un compte** — cette personne utilise déjà SportyPlus, par exemple dans un autre club. Elle rejoint votre club avec son compte existant au lieu d'en recevoir un second.
- **Déjà membre** — la personne est déjà dans votre club. Seuls l'adhésion et le solde du fichier sont ajoutés.
- **Junior** — un enfant sans e-mail propre. Il est ajouté sous le compte du parent indiqué dans `guardian_email`, qui doit figurer dans le même fichier ou déjà utiliser SportyPlus. [Famille et enfants](/fr/members/family) explique comment les parents gèrent leurs enfants.
- **En double dans le fichier** — le même e-mail apparaît plus haut dans le fichier. La ligne est ignorée.
- **À corriger** — quelque chose doit d'abord être corrigé, comme un nom manquant ou une adhésion inconnue. La ligne est ignorée, et la remarque indique le problème.

Activez **Afficher uniquement les lignes avec des remarques** pour ne voir que les lignes à vérifier.

### Adhésions

La colonne `membership` doit correspondre au nom d'une adhésion que votre club a déjà, dans l'une de ses langues. Sinon, la ligne est à corriger : créez d'abord l'adhésion sous [Adhésions](/fr/interface/memberships), ou changez le nom dans le fichier.

- Le membre garde l'adhésion jusqu'à la date de `membership_end`. Sans date de fin, l'adhésion n'expire pas.
- Une adhésion déjà terminée n'est pas importée.
- Si le membre a déjà cette adhésion, elle reste telle quelle.
- Les membres ne reçoivent pas d'e-mail « merci pour votre achat » pour une adhésion importée. Ils ont payé votre ancien système, pas SportyPlus.

### Crédit prépayé

Un `balance` positif est ajouté au porte-monnaie du membre dans votre club comme solde d'ouverture, avec la mention qu'il provient du système précédent. Les membres peuvent l'utiliser tout de suite pour réserver.

Un solde négatif n'est pas importé. Réglez les sommes dues par un membre avant le changement.

### Importer à nouveau le même fichier

Vous pouvez recharger le fichier, par exemple après avoir corrigé les lignes concernées. Les membres déjà importés apparaissent comme **Déjà membre**, et leur adhésion et leur solde d'ouverture ne sont pas ajoutés une seconde fois.

### Prévenir les membres

Personne ne reçoit d'e-mail, sauf si vous cochez **Envoyer aux nouveaux membres un e-mail expliquant comment se connecter**. Dans ce cas, chaque nouveau membre reçoit un e-mail de votre club. Il indique que son compte est prêt et que son adhésion a été transférée, avec un lien vers votre page de connexion, où il choisit **Mot de passe oublié ?** pour définir son propre mot de passe.

Laissez l'option désactivée si vous préférez prévenir les membres vous-même, par exemple une fois la date du changement fixée. Ils peuvent se connecter de la même manière à tout moment.

## Importer des réservations récurrentes

Les réservations hebdomadaires fixes, comme le terrain d'un membre le mardi soir, peuvent aussi être importées. Allez dans **Club Admin → Communauté → Membres → Importer des réservations récurrentes**.

Chaque ligne est une réservation hebdomadaire :

| Colonne | Contenu |
| --- | --- |
| `email` | L'e-mail du membre. Il doit déjà être membre de votre club. |
| `court` | Le nom du terrain, tel qu'il s'appelle dans SportyPlus |
| `weekday` | Le jour, en toutes lettres (mardi, Tuesday) ou en chiffre (1 = lundi) |
| `start` | L'heure de début, par exemple 18:00 |
| `end` ou `duration` | L'heure de fin, ou la durée en minutes |
| `first_date` | La première date. Vide signifie demain. |
| `last_date` | La dernière date. Obligatoire. |
| `name` | Facultatif, affiché sur la réservation |

SportyPlus réserve le terrain chaque semaine ce jour-là, de la première à la dernière date. Seules les dates futures sont réservées, et jamais plus de 52 semaines à l'avance. Une réservation plus longue doit être renouvelée plus tard.

L'aperçu vérifie déjà chaque date par rapport aux réservations de vos terrains. Une date où le terrain est pris est ignorée et listée avec la raison, et rien n'est écrasé. Si vous importez à nouveau le même fichier, les dates réservées la première fois apparaissent comme prises, donc rien n'est réservé deux fois.

Les réservations importées sont gratuites pour le membre, avec la mention qu'elles ont été importées, car le membre les a payées à votre ancien système. Les limites de réservation des adhésions ne s'appliquent pas, et les horaires d'ouverture ne sont pas vérifiés, comme lorsqu'un administrateur réserve un terrain. Les membres ne sont pas prévenus des réservations importées.
